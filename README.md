# プロジェクト概要

> 本多浩道の「本の要約文に対する感想」を蓄積し、その傾向を言語化するプロジェクト。

## 目的

本の要約文に対する本多自身の「感想」を集め、同時に本多自身の思考・文章の傾向をまとめる。

## 最終目的

蓄積した感想と傾向の情報をもとに、**新しい本の要約文を読み込んだら、本多がどの部分に着目し、どんな感想を持つかを出力する**こと。本多の視点を再現する仕組みをつくる。

## 構成要素

- **要約文原文**: 感想の対象となった本の要約文そのもの。感想とペアで蓄積し、どの記述に反応したかを後から辿れるようにする。
- **感想データ**: 本の要約文に対する本多の実際の感想。着目点と、それに対する反応を蓄積する。
- **傾向まとめ**（[傾向まとめ.md](傾向まとめ.md)）: 感想から抽出した、思考・文章の傾向。随時更新される基盤ファイル。

## ファイル構成

```
flier/
├── README.md             … このファイル（プロジェクト概要）
├── CLAUDE.md             … 作業マニュアル（セッションの入口）
├── 傾向まとめ.md         … 思考・文章の傾向（基盤ファイル）
├── 読書傾向.md           … どんな本を選びがちか（選書の傾向）
├── 自己像.md             … 平易な言葉でまとめた人物像
├── ルール.md             … 作業時に守る共通ルール
├── 運用モード.md         … 操作モードの定義（start で選択）
├── 索引.md               … 蓄積した本の一覧と保存ルール
├── 要約文原文/           … 本ごとの要約文原文（番号_タイトル.md）
└── 感想データ/           … 本ごとの感想（要約文原文と同名でペア）
```

要約文原文と感想データは同じ通し番号・同じファイル名でペアにし、追加のたびに `索引.md` に1行足す。

## 進め方

感想が増えるほど傾向の解像度が上がり、傾向が明確になるほど要約文への感想予測の精度が上がる——という往復で育てていく。

## 使い方

このリポジトリは Claude Code で運用する。作業の入口は [CLAUDE.md](CLAUDE.md)（セッション冒頭で必ず読む運用マニュアル）。`start`（記号なしの語）を入力するとモード選択（インプット／アウトプット／メンテ）が表示される。各ドキュメントの詳細は上のファイル構成を参照。
